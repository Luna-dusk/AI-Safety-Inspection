# 触摸屏 UI 原型说明（240×320）

> 配套文件：`ui/prototype/index.html`（交互原型）、`ui/shots/*.png`（各屏截图）
> 状态：可点击演示，**未接任何业务逻辑**；LVGL 侧尚未实现。

---

## 1. 设计北极星

**「一眼看见自己在被守护，一眼能找到求救」** —— 这是台安全设备，不是智能音箱。

三个决定都从这句推出来：

| 决定 | 依据 |
| --- | --- |
| 主屏第一眼是**监护状态**（大卡 + 绿色进度环），不是功能宫格 | FR-2/FR-10：用户要确认「它在盯着」，不是来逛功能的 |
| **紧急呼救**固定在主屏第二视觉层（整条红色卡片），且全屏只有这一处红 | 丢了红就丢了产品；但红多了就不红 |
| 三条主动告警全部**不依赖 UI**：界面只负责「确认、撤销、看结果」 | 需求开篇就写「不依赖用户按键」，UI 不能变成报警前置条件 |

反面参考：不做轮播、不做彩色大图标宫格、不做动画背景 —— 240×320 只有 76800 个像素，一屏最多容纳 3 个决策点。

## 2. 界面清单与导航

```
             ┌──────── 主屏 · 守护 ─────────┐
             │  守护状态卡 → 事件记录        │
             │  [事件]  [AI 对话]  ← 两张卡 │
             │  紧急呼救 → 呼救中            │
             └──┬──────┬──────┬──────┬─────┘
              底部导航 4 项，只在主屏出现
       对讲 ←──┘      │      │      └──→ 设置
                    应用商店          ↑ 返回
                       │
   事件记录 ──(第 1 条)──→ 收到告警 ──(我已到场)──→ 主屏
```

| # | 屏 | 存在的理由 | 对应需求 |
| --- | --- | --- | --- |
| 1 | 主屏 · 守护 | 静默计时、是否在监护、电量信号一眼可见 | FR-2 / FR-10 |
| 2 | 对讲 · 双机 | 按住说话 + 对端在线/同网/电量/距离 | FR-4 / FR-5 |
| 3 | 紧急呼救 · 多渠道投递 | 把「本机/对端/家属」三条投递结果**显示出来**，可撤销 | FR-1 / FR-6 |
| 4 | 收到告警 · 对端跌倒 | 对方出事时：谁、什么事件、多远、要不要过去 | FR-4 |
| 5 | 事件记录 | 可追溯，未读/已回执/已撤销 | FR-6 / FR-11 |
| 6 | 应用商店 | 装完即玩，且明示「不影响监护」 | FR-7 |
| 7 | AI 对话 · 操作确认 | 会「发出/改动」的操作必须复述后确认 | FR-8 / FR-9 |
| 8 | 设置 | 静默阈值、免打扰、灵敏度、音量、开关 | FR-2 / FR-3 / FR-5 |

所有屏共 37 个可点区域；点进去不跳转的地方会弹提示（演示用，不在画面上写「未接入」）。

## 3. 视觉规范（可直接抄进 LVGL 主题）

### 色彩

| 名称 | Hex | 用途 |
| --- | --- | --- |
| `BG` | `#0B1116` | 屏幕底色 |
| `SURFACE` | `#151D24` | 卡片 |
| `LINE` | `#2B3842` | 卡片描边（1 px） |
| `TEXT` | `#F2F7FA` | 主文字 |
| `MUTED` | `#A8B9C4` | 次文字（已从 #8FA2AE 提亮一档，老年户外对比度） |
| `ACCENT` | `#3DDC97` | 正常/在线/已送达（唯一的「安心色」） |
| `AMBER` | `#FFB020` | 需要确认、降级、进行中 |
| `RED` | `#FF5A5F` | 只用于呼救与告警 |
| `RED_BG` | `#1A0D10` / 卡 `#2A1216` | 告警屏底色 |
| `OK_BG` | `#16302A` | PTT 按钮底 |
| `DISABLED_BG` | `#141B20` / 描边 `#38444D` | 对端离线时的 PTT |

暗色 + 高对比：夜间跌倒场景下不刺眼，绿色表示「一切正常」在暗底上最亮。红/琥珀/绿三色语义严格分离，**不用颜色表达装饰**。

### 字号（只有 4 档，中文不再做粗体）

| 档 | 用途 | LVGL |
| --- | --- | --- |
| 28 | 告警标题、倒计时数字 | Montserrat 28（数字）+ 中文 28 |
| 20 | 屏内主标题 | 中文 20 |
| 16 | 卡片标题、按钮、列表主行 | 中文 16（主力字号） |
| 12 | 说明、状态、时间 | 中文 12 |

> 中文不做 bold：LVGL 里每个字号都要单独一份字库，粗体等于再翻一倍 Flash。层级靠**字号 + 颜色**，不靠字重。数字用 Montserrat（LVGL 自带，可粗）。

### 尺寸

- 画布 240×320，安全边距 **8 px**，内容宽 224
- 圆角：大卡 14、普通卡 12、筛选/开关胶囊 9–13
- 间距：4 px 网格，卡间距 8，区域间距 6–8
- 触摸最小 **44×44**：底部导航 60×48、列表行 224×52、按钮 108×44
- 描边 1 px，**无阴影、无渐变、无毛玻璃**（LVGL 上都不便宜，也没必要）

## 4. 关键状态（不只是漂亮默认态）

| 状态 | 在哪里体现 | 实现方式（原型） |
| --- | --- | --- |
| 对端在线 / **不在同一网络** | 对讲屏：横幅换文案换色 + **PTT 整块降饱和禁用**（灰环、灰麦、文案「暂时无法呼叫」）+ 视线下方改为「等待对方回到同一网络」；同屏不再出现「通话中」 | `svg[data-peer="offline"]` 切换 `.peer-on` / `.peer-off` 两组节点；右下「对端离线」按钮可看 |
| 告警撤销 | 呼救屏底部「我没事 · 取消报警」**同样要长按 3 秒**（左侧环形进度 + 「长按 3 秒才生效」），与主屏触发门槛对称 | 静态稿只表达「有门槛」；实际交互未验证 |
| 多渠道投递进度 | 呼救屏三行：本机✓ / 对端✓ / 家庭群「发送中」 | 静态示意，LVGL 里用 3 个 row 的状态机 |
| 待确认操作 | AI 屏琥珀色卡：复述对象+内容，「取消 / 确认」 | 静态 |
| 未读 | 主屏「2 条未读」= 列表里 2 个红点 | 两屏一致 |
| 严重度 | 跌倒卡整张变红面（背景+描边+标题），其余卡保持中性 | 不读字也能认出 |

## 5. 移植到 LVGL：一一对应

原型里每个元素的 `x/y/width/height` 就是 `lv_obj_set_pos/size` 的参数，`rx` 就是 `radius`，坐标已是 4 的倍数，不需要换算。

| 原型 | LVGL 做法 |
| --- | --- |
| 一屏 `<g class="screen">` | 一个 `lv_obj_create(NULL)` + `lv_scr_load_anim(scr, LV_SCR_LOAD_ANIM_MOVE_LEFT, 180, 0, false)` |
| 卡片 `rect rx=12 fill=SURFACE stroke=LINE` | `lv_obj` + `radius 12` + `bg_color` + `border_width 1` + `border_color`；`pad 0`，子对象绝对定位 |
| 文字 `f16` | `lv_obj_set_style_text_font(obj, &ui_font_16, 0)`（lv_font_conv 子集，只收本 UI 用到的字） |
| 数字 28 `font-weight:600` | `lv_font_montserrat_28`，不需要中文 |
| 绿色进度环（141/189） | `lv_arc`：`lv_arc_set_bg_angles(0,270)`、`lv_arc_set_range(0,100)`、`lv_arc_set_value()`、`LV_PART_INDICATOR` 加 `arc_rounded = 1`、宽度 5 |
| 可点区域 `<g class="tap">` | `lv_obj_add_flag(obj, LV_OBJ_FLAG_CLICKABLE)` + `lv_obj_add_event_cb(obj, cb, LV_EVENT_CLICKED, (void*)ID)` |
| SOS 长按 3 秒 | `LV_EVENT_PRESSED` 起 `lv_timer` 3000ms + 环形进度；或 `LV_EVENT_LONG_PRESSED`（默认 400ms，需 `lv_indev_set_long_press_time(3000)` 改全局，不推荐） |
| 开关 | `lv_switch`，尺寸 32×18（`lv_obj_set_size` 后 knob 半径 7） |
| 筛选胶囊 | `lv_btn` + `radius 13` + `LV_STATE_CHECKED` 样式 |
| 事件列表 | 容器 + `LV_OBJ_FLAG_SCROLLABLE` + flex column，行高 52、间距 8；**不要用 `lv_list`**（样式不好控） |
| 底部导航 | 4 个 60×48 可点 `lv_obj`，激活/未激活两套样式（`ui_nav_set_active(i)`） |
| 图标（铃、麦克、盾、齿轮…） | 3 种走法：① 8 个 16×16 / 24×24 **透明 PNG**（最省事、最好看）② LVGL 内置 symbol 字体 ③ `lv_canvas` 画。建议 ① |
| 屏返回栈 | 自己维护 `ui_stack[8]` + `ui_back()`，与原型 JS 同一套逻辑 |
| 状态变体（对端离线等） | 单函数 `ui_talk_set_peer(UI_PEER_ONLINE/OFFLINE)`：改 label 文本 + 卡片 `bg/border` 颜色 + 图标显隐。**不要在 C 里留两套界面** |

### 建议的组件分层

```
ui/
  ui_theme.c/h        颜色宏、字号指针、半径常量、公共 style
  ui_nav.c/h          屏路由 + 返回栈 + 底部导航状态
  ui_widgets.c/h      card()、row()、pill()、switch_row()、icon()
  screen_home.c / screen_talk.c / screen_sos.c / screen_alarm.c
  screen_events.c / screen_apps.c / screen_chat.c / screen_settings.c
```

每个屏一个文件、一个 `create()`、一个 `refresh()`（从 `app_state` 拉数据）。界面只读状态，不写业务。

### 移植顺序（建议）

1. 先做 `ui_theme` + 主屏一张卡（文字 + 圆角 + 描边），确认字库、颜色、触摸三点都对；
2. 再做导航 + 主屏全部可点区，把 8 个屏都做成**空壳**（只有标题），跑通跳转和返回；
3. 然后按屏补内容，顺序：对讲 → 呼救 → 收到告警 → 事件 → 设置 → 商店 → AI（前四个是 P0）；
4. 最后接状态：监护中/静默计时、对端在线、电量、告警中。

## 6. 字体与资源

- 中文：`Noto Sans SC` / `Source Han Sans SC`（开源，可商用）。用 `lv_font_conv --bpp 4 --format lvgl --size 12,16,20,28 --symbols <本 UI 用到的字>` 生成子集，四档合计约 200–400 KB（远小于全字库）。
- 数字：`lv_font_montserrat_28`（LVGL 内置），比中文字库便宜得多。
- 图标：建议导出 PNG（带透明），16 与 24 两种尺寸，随屏一起打包进 SPIFFS/分区。

## 8. 怎么看 / 怎么改

```bash
# 直接双击打开，或
xdg-open ui/prototype/index.html

# 直接定位某一屏、看对端离线、只看设备
ui/prototype/index.html?screen=talk&peer=offline
ui/prototype/index.html?bare=1&screen=alarm      # 隐藏外围面板，只剩 240×320
ui/prototype/index.html?bare=1&view=overview     # 8 屏并排总览
```

面板右侧：跳转按钮、**对端离线**开关、全部屏总览、**导出当前屏 SVG**（导出的是干净单屏，可直接给设计/评审看）。

改法：所有屏都在同一个 `<svg>` 里，坐标写死在属性上，改一个数字即可；配色集中在 `<style>` 里（`--` 变量只在外层 HTML 用，SVG 内是字面色值，方便对着改 LVGL 宏）。
